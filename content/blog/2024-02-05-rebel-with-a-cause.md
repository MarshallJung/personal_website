Hotelling’s Law:

Rival products (burgers, pop songs, political parties) tend to grow more alike over time, because creators copy more successful rivals to replicate their success and steal their customers/audiences. Paradoxically, this increases the value of being different.

I’m not sure if this is something that has always served me 100% well, but I do seem to have a built in need to be different. I certainly don’t think I’m first to most ideas, but some of my best successes in life have come from looking at the way everyone else does things and asking why. In the world of innovation being different is good as long as the ideas tried are held loosely and the iterations come fast.

### What does the current 3D ML world look like?

[https://huggingface.co/papers/2401.17807](https://huggingface.co/papers/2401.17807)

This reference covers a good deal of existing 3D generation methodologies. From 3D-GAN through to generative methods there are some really fast moving concepts out there. Sorting seems to be modeled on the underlying algorithmic methods, input imagery and compute requirements. Good place to start with understanding the fundamentals.

### A picture (method) is worth a 1000 words?

[https://huggingface.co/papers/2401.17181](https://huggingface.co/papers/2401.17181)

Google released a paper that proposes replacing the autoregressive decoding process in training and deployment of LLM’s with a diffusion based method on top of pretrained models. Since the concept of language is valid for images and algorithms like DALL-E and Midjourney use diffusion to go from text to image, it stands to reason that there may be a way to use the diffusion methods to “imagine” text. I do wonder if this will have better applications in the world of creative writing rather than in places like legal or coding where the results need to be more structured and accurate.

### Vectoring towards success

[https://huggingface.co/papers/2401.17093](https://huggingface.co/papers/2401.17093)

Using the concept of breaking down a 2D vector to gridded quanta allows those individual tokens to be understood by an LLM. I think the extension of this concept lies in the discretization at a standard level for ingestion of vectors making the process extensible across any given image. I think there might be a case to be made for this process in three dimensions as well.

### Next generation coding model

[https://arxiv.org/abs/2401.08500](https://arxiv.org/abs/2401.08500)

Interesting work that shows just how much value there is from building complex prompt flows in this case for code generation. I think this works better for code than other written LLM output specifically because of the chain of reasoning that holds true for code. With a flavor of Meta’s self rewarding model design, there are two additions that seem to be proposed. Pre-processing, or transforming the original problem statement into something more concise and parsable by the model, forcing the model to explain the results (why test input leads to a certain output), rank various solutions, etc. And an iterative loop where the model fixes its solution code against a set of tests.
